## Common Key mappings

#### Tabs and Buffer Navigation

| Action | Keymap |
| ------ | ------ |
| Next Buffer |`<leader>w` |
| Previous Buffer | `<leader>q` |
| Buffer 1-10 | `<leader>[1-10]` |
| Next Tab | `<leader>n` |
| Directory Explorer | `<leader>d` |

#### Finding

| Find | Keymap |
| ------ | ------ |
| Files |`Ctrl-f` |
| Word | `<leader>fw` |
| Buffer | `<leader>fb` |
| Grep | `<leader>fg` |
| Git Branch | `<leader>gb` |
| Git Stash | `<leader>gs` |

#### Language Navigation

| Action | Keymap |
| ------ | ------ |
| Definition | `gd` |
| Declaration | `gD` |
| Implementation | `gi` |
| References | `gr` |
| Workspace Symbols | `gs` |
| Signature Help | `gk` |
|  Hover | `K` |
| Toggle Inlay Hints | `<leader>ih` |
| Symbol Overview | `<leader>s` |

#### Tasks

| Action | Keymap |
| ------ | ------ |
| Open Terminal | `<leader>t` |
| Run Task | `<leader>or` |
| Current Task Info | `<leader>ot` |

For information on tasks can be found [tasks.md](tasks.md)
